#+property: header-args:python :results output :exports both
#+startup: inlineimages

/The three lines above were generated by the =pyheader= yasnippet./

The =#+property= line declares only the two defaults that apply to *every* Python
block in this file: =:results output= (stdout is captured into =#+RESULTS:=) and
=:exports both= (code and results both appear in HTML / PDF export).  The session
name and output directory are *not* set at the file level — each block carries its
own =:session py= (via the snippets) and plot blocks embed the =._aux/= prefix
directly into the =:file= header and =fig.savefig()= path.  The file is therefore
self-contained and runs the same way on any machine, regardless of the
recipient's Emacs config.

Run the setup block once (=C-c C-c=) before any plot block. =C-c C-v C-i=
shows the merged header args for the block at point.

* Setup                                                            :noexport:
/The block below was generated by the =pysetup= yasnippet./

=MPLBACKEND=Agg= must be set *before* matplotlib is imported: it prevents
macOS from loading AppKit (which writes =ApplePersistence=NO= to stderr and
pops =*org-babel error output*=).

#+name: setup
#+begin_src python :session py :results silent
import os
os.environ.setdefault("MPLBACKEND", "Agg")

import numpy as np
import matplotlib.pyplot as plt

plt.rcParams.update({
    "figure.figsize": (6, 4),
    "axes.grid": True,
    "savefig.format": "svg",
})

#+end_src

** Basic line plot

#+begin_src python :session py :file ._aux/example.svg :results file graphics
fig, ax = plt.subplots()
x = np.linspace(0, 2*np.pi, 100)
ax.plot(x, np.sin(x), label="sin")
ax.plot(x, np.cos(x), label="cos")
ax.legend()
ax.set(xlabel="x", ylabel="y", title="Plot title")
fig.savefig("._aux/example.svg")
#+end_src

** Multiple subplots
#+begin_src python :session py :file ._aux/subplots.svg :results file graphics
fig, axes = plt.subplots(1, 2, figsize=(10, 4))
x = np.linspace(-3, 3, 200)

axes[0].plot(x, np.tanh(x))
axes[0].set_title("tanh")

axes[1].plot(x, 1 / (1 + np.exp(-x)))
axes[1].set_title("sigmoid")

fig.tight_layout()
fig.savefig("._aux/subplots.svg")

* Notes
- =C-c C-c= executes the block at point.
- =C-c C-v C-b= executes all blocks in the buffer, top to bottom.
- =C-c C-x C-v= toggles inline image display.
- Kill the session with =M-x kill-buffer RET *Python[py]* RET= when you
  want a clean slate.
- Each plot block creates its own =fig, ax= — otherwise =plt= would keep
  drawing on the previous figure since the session persists.
