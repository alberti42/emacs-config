The =#+property= line fully specifies the Python defaults for this file (no
=+=, so it replaces any user-global defaults): a dedicated session named
=pyplot-tutorial=, stdout-style results, both code and output in exports,
and =:dir ._aux= so every block runs with =._aux/= as its working directory
(org-babel auto-creates the directory).  The file is therefore
self-contained and runs the same way on any machine, regardless of the
recipient's Emacs config.

*Caveat:* =:dir= also affects relative paths used *inside* blocks. A block
that does =np.load("data.npy")= or =open("config.txt")= will look for those
files in =._aux/=, not the org file's directory.  When you need to load
data from the org file's directory, override per-block with =:dir .= (or an
explicit path).

Run the setup block once (=C-c C-c=) before any plot block. =C-c C-v C-i=
shows the merged header args for the block at point.

* Setup                                                            :noexport:
/The block below was generated by the =pysetup= yasnippet./

=MPLBACKEND=Agg= must be set *before* matplotlib is imported — it prevents
macOS from loading AppKit (which writes =ApplePersistence=NO= to stderr and
pops =*org-babel error output*=).

#+name: setup
#+begin_src python :results silent
import os
os.environ.setdefault("MPLBACKEND", "Agg")

import numpy as np
import matplotlib.pyplot as plt

plt.rcParams.update({
    "figure.figsize": (6, 4),
    "axes.grid": True,
    "axes.spines.top": False,
    "axes.spines.right": False,
    "savefig.format": "svg",
})
#+end_src

#+begin_src python :file sine.svg :results file graphics :dir ._aux
fig, ax = plt.subplots()
x = np.linspace(0, 2*np.pi, 200)
ax.plot(x, np.sin(x), label="sin")
ax.plot(x, np.cos(x), label="cos")
ax.legend()
ax.set(xlabel="x", ylabel="y", title="Trigonometric")

  fig, axes = plt.subplots(1, 2, figsize=(10, 4))
  x = np.linspace(-3, 3, 200)

  axes[0].plot(x, np.tanh(x))
  axes[0].set_title("tanh")

  axes[1].plot(x, 1 / (1 + np.exp(-x)))
  axes[1].set_title("sigmoid")

* Notes
- =C-c C-c= executes the block at point.
- =C-c C-v C-b= executes all blocks in the buffer, top to bottom.
- =C-c C-x C-v= toggles inline image display.
- Kill the session with =M-x kill-buffer RET *Python[pyplot-tutorial]* RET=
  when you want a clean slate.
- Each plot block creates its own =fig, ax= — otherwise =plt= would keep
  drawing on the previous figure since the session persists.
