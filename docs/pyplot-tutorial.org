* Plots
/All three blocks below were generated by the =pyplot= yasnippet./

Plot blocks override =:results= to =file graphics= so org inserts the saved
figure as an inline image.  =rcParams["savefig.format"] = "svg"= from setup
means =plt.savefig("name")= without extension writes SVG, but =:file= here
must still include the extension so org inserts the correct link.

** Basic line plot
#+begin_src python :file sine.svg :results file graphics
fig, ax = plt.subplots()
x = np.linspace(0, 2*np.pi, 200)
ax.plot(x, np.sin(x), label="sin")
ax.plot(x, np.cos(x), label="cos")
ax.legend()
ax.set(xlabel="x", ylabel="y", title="Trigonometric")
fig.savefig("sine.svg")
#+end_src

** Multiple subplots
#+begin_src python :file subplots.svg :results file graphics
fig, axes = plt.subplots(1, 2, figsize=(10, 4))
x = np.linspace(-3, 3, 200)

axes[0].plot(x, np.tanh(x))
axes[0].set_title("tanh")

axes[1].plot(x, 1 / (1 + np.exp(-x)))
axes[1].set_title("sigmoid")

fig.tight_layout()
fig.savefig("subplots.svg")
#+end_src

* Notes
